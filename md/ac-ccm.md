# AC-CCM

AC-CCM 是一个面向中国民乐意境识别的数据集。数据集以清代琴学经典《溪山琴况》的“二十四况”理论为基础，面向中国音乐的情感、意境与审美语义理解任务构建，可用于音乐意境识别、音频分类、多标签标注预测以及传统音乐审美概念与音频特征关系研究。

## 数据集信息

| 项目 | 内容 |
| --- | --- |
| 数据集名称 | AC-CCM |
| 英文名称 / 缩写 | AC-CCM |
| 数据对象 | 中国民乐 |
| 理论基础 | 《溪山琴况》二十四况 |
| 主要任务 | 中国民乐意境识别、音乐情感 / 审美语义理解、音频分类与多标签预测 |
| 标注类型 | 《溪山琴况》二十四况相关意境标签 |

该数据集围绕《溪山琴况》提出的二十四况展开，用于描述中国民乐中的意境、气质与审美特征。与常见的情绪分类数据不同，AC-CCM 更关注中国传统音乐语境中的审美语义表达，为音乐信息检索、计算音乐学和中国传统音乐智能理解提供实验资源。

后续可在本节进一步补充数据规模、乐器构成、音频格式、标注粒度、字段定义和质量控制流程。现阶段可描述的字段包括曲目或音频片段编号、音频路径或相对索引、意境标签、乐器信息，以及曲目、版本、演奏者等元数据。

## 获取方法

本网站暂不直接提供数据集下载链接。若您希望获取 AC-CCM 数据集，请通过邮件联系维护团队申请。

- 申请邮箱：[xiafan@zjcm.edu.cn](mailto:xiafan@zjcm.edu.cn)
- 邮件标题建议：`数据集申请 - AC-CCM - 申请人姓名/单位`
- 邮件内容建议包含：申请人姓名、单位与联系方式、研究目的或项目简介、是否需要样例数据、是否需要引用或再分发说明。

维护团队将在收到申请后，根据数据集许可、使用范围和共享条件进行回复。

## 使用许可说明

AC-CCM 的使用许可、共享范围与再分发要求以维护团队邮件回复为准。未经授权，请勿将数据集二次分发、上传至第三方平台，或用于超出许可范围的用途。使用数据集发表论文、报告或公开展示成果时，应按维护团队要求引用相关论文或注明数据来源。

# GuzhengTech99 demo assets

Source: user-supplied Guzheng_Tech99.zip, corresponding to https://lidcc.github.io/GuzhengTech99/ and https://huggingface.co/datasets/ccmusic-database/Guzheng_Tech99.

License: CC BY-NC-ND 4.0 (https://creativecommons.org/licenses/by-nc-nd/4.0/).
Creators: Dichucheng Li, Mingjin Che, Wenwu Meng, Yulun Wu, Yi Yu, Fan Xia, Wei Li.

One shortest complete recording from each original split is included. FLAC audio and matching CSV annotations are copied byte-for-byte without modification. File IDs are preserved; no track titles are inferred. samples.json records source split, audio properties, annotation row counts, technique labels and checksums.

Paper: Frame-Level Multi-Label Playing Technique Detection Using Multi-Scale Network and Self-Attention Mechanism, ICASSP 2023.
